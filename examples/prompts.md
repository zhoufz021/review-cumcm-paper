# 调用提示词示例

## 快速预检

```text
$review-cumcm-paper

请对附件论文执行 quick 模式预检。先核对材料是否可读，再检查摘要、原题小问覆盖、图表、引用、逐问结果和明显缺漏。不要输出获奖预测。请按影响排序，给出不超过10条可立即修改的问题。
```

## 全面审核

```text
$review-cumcm-paper

请按 full 模式全面审核附件论文。原始赛题、论文、数据附件和代码均已提供。

请完成：
1. 原题小问索引；
2. 小问—分析—模型—结果—验证矩阵；
3. 四态证据账本；
4. 十二维评分和题型专项检查；
5. 带原文位置的分级问题清单；
6. 最优先五项修改；
7. 每项修改的完成性测试。
```

## 材料不完整的全面审核

```text
$review-cumcm-paper

请审核附件论文，但目前没有代码和原始数据。不得把未提供材料当作错误；对实现正确性和数据处理细节使用 unverifiable，并说明需要补充哪些材料。其余可见内容按 full 模式审核。
```

## 修改复审

```text
$review-cumcm-paper

请按 re-review 模式复审修改稿。附件包括修改稿、上一轮审核报告和修改前论文。

冻结上一轮问题编号和完成标准；逐项判断 resolved、partially_resolved、unresolved 或 unverifiable；检查修改前后文件不同；把新增回归单独编号并给出位置。
```

## 只审核验证与稳健性

```text
$review-cumcm-paper

请聚焦“验证与稳健性”维度。按对象—基准/真值—指标—结果—结论影响检查每个小问，不要把模型评价标题、拟合图、收敛图或随机模拟本身视为完整验证。
```
