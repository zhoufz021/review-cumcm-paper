# 使用指南

## 1. 准备材料

全面审核至少提供：

- 待审核论文 PDF 或 DOCX；
- 原始赛题；
- 竞赛、年份和题号。

建议同时提供赛题附件、数据、代码、官方格式要求和上一轮审核报告。缺少可选材料不会自动扣分，但会降低相应结论的可核验性。

## 2. 选择模式

### 快速预检 `quick`

适合提交前快速排查。通常输出 5—10 个确定性较高的问题，不建议输出总分。

```text
$review-cumcm-paper

请对附件论文执行 quick 模式预检。
重点检查摘要、原题小问覆盖、图表、引用、结果表达和明显缺漏。
按优先级输出10条以内的修改建议。
```

### 全面审核 `full`

适合完整诊断和修改规划。

```text
$review-cumcm-paper

请按 full 模式审核附件论文。
竞赛：CUMCM 2024
题号：A
附件包括原始赛题、论文、数据和代码。

要求：
1. 从原始赛题建立小问索引；
2. 建立小问—模型—结果—验证矩阵；
3. 执行十二维评分和题型专项检查；
4. 所有重要意见给出原文位置；
5. 输出修改建议和可复核的完成标准。
```

### 修改复审 `re-review`

适合检查上一轮问题是否真正闭环。

```text
$review-cumcm-paper

请按 re-review 模式审核修改稿。
附件包括修改稿和上一轮审核报告。

逐项判断：已解决、部分解决、未解决或无法核验；
检查摘要、正文、图表、结论和附件是否同步；
将修改产生的新问题单独编号。
```

## 3. 证据状态

- `present`：有明确且可定位的证据；
- `missing`：要求适用，经可靠检查确认缺失；
- `not_applicable`：要求不适用，不进入分母；
- `unverifiable`：材料或抽取限制导致无法判断，不记 0 分。

## 4. 总分规则

只有当已评分权重不少于适用权重的 80% 时才显示归一化总分。总分只用于修改排序，不代表官方成绩。

## 5. 文件格式

- PDF：使用文件页序定位；文本层稀疏时执行 OCR 或视觉核验；
- DOCX：使用标题路径、段落和表格定位，不虚构分页；
- DOC：脚本不支持，先转换为 PDF 或 DOCX；
- Markdown/TXT：可用于已抽取文本的审核，但公式和图表通常需要回看原文件。

## 6. 常见问题

### 没有原始赛题怎么办？

可以审核写作、图表和局部建模表达，但任务数量、覆盖和题意符合性必须标记为无法核验。

### 没有代码和数据会扣分吗？

不能因材料未提供就判定实现错误。可根据正文说明审核复现性，并把实现正确性标记为无法核验。

### 为什么没有总分？

通常是可评分权重低于 80%，或者多个关键维度因材料不足无法核验。

### 可以预测获奖吗？

不可以。量表只用于定位问题和安排修改优先级。
